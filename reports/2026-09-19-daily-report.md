今日热榜几乎被编码代理生态占据：从 Claude Code 的配置兼容更新，到 ECC、agent-skills、OpenSpec 等围绕代理技能、记忆与规格驱动开发的工程化项目，工具链正快速走向成熟。与此同时，ArXiv 上多篇论文聚焦编码代理的 harness 设计与代理式强化学习，说明“如何让代理更可靠地工作”已成为研究与工程共同的核心议题。另一条值得关注的线索是效率与安全并重，既有 8–29MB 的小型自动化模型对标大模型，也有关于 LLM 安全、过度宣称与偏见“洗白”的实证研究。
